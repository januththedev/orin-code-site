Getting started

  1. Windows app — download the installer from the homepage, sign in with your Orin account (same as Orin Chat), open a project and start chatting with your code.
  2. CLI — install from GitHub for agentic coding in any terminal.
  3. VS Code extension — add Orin to VS Code and keep your existing setup.

Phone approvals

Risky actions can ask for approval on your phone before they run — pair once, approve anywhere. Your account, your keys, your machine.
