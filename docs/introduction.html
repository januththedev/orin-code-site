Introduction

Orin Code is a free AI coding workspace: a chat sidekick, an IDE, a real terminal, MCP tools, computer-use automation and phone approvals — in one Windows app, with your Orin account throughout.

Three ways to work

  • Windows app — the full workspace: chat, edit, run, approve from your phone.
  • CLI — the same agent power in your terminal, installed from GitHub.
  • VS Code extension — Orin inside the editor you already use.
